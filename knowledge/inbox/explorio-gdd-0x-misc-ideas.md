### Seed Save

- Text File to keep information of the game
  - List of map seeds
  - Game version when seed created
  - Date of seed creation
- In Game Menu to see recent ( Or all ) game seeds that were used
- Player Character as a Folder
  - This is saved in Steam Save Cloud
  - Player has multiple ( Default 3 Save Slots - Similar to Unexplored ) Save Folders
