# Explorio | 05 | Gameplay and Progression Systems

Navigation: [[wiki/maps/explorio-knowledge-map|Knowledge map]]

- Language: mostly English; the inventory section has a block of untranslated

- Subtitle in the doc: "Adventurer's Handbook – A Beginner's Guide to Explorio's
  Dungeon Delving and Player Progression".

## Summary

A brainstorm-level GDD chapter on everything the player brings into a dungeon:
controls (two hands, grab, crouch/investigate, interact, cape skill), attributes
(STR/DEX/INT/WIS with mostly design-question tables, no final formulas),
inventory and layered gear, the hub town (mission table with seeded dungeons,
five merchants and a temple that give tips based on the last run, secret NPC
bosses), meta progression (vertical vs horizontal unlocks, XP sources per
STR/DEX/INT tree), 15 unlockable classes, a large achievement catalogue and
seasonal events. Many sections are stubs (Resources, Horizontal unlock examples,
Starting Items, cosmetics). For the generator, the useful content is the set of
player verbs and class kits that can act as keys, and the run-level facts
(seeds, bosses, layers, biome tiers) hidden in the achievement lists.

## Section outline

- Game Basics – Controls (gamepad schemes A/B, keyboard scheme)
- Player Character
  - Attributes – Core Concepts (mind–body dualism, base and derived stats,
    attribute requirements, systems that need to be acknowledged), Base stats,
    Main stats
  - Inventory – Equipped Items, Inventory / Backpack, Stats / Character Sheet,
    Journal / Discovered Items (plus untitled Polish notes)
  - Classes – Core Concepts (gameplay focus, rock–paper–scissors), Resources (empty)
- Hub Town – Main points of interest (Mission table, Training grounds,
  Marketplace with five shops, Temple); Town Secrets – Bosses (six NPC bosses)
- Meta Progression – Skill Trees (vertical, horizontal, experience sources,
  perks overview); Unlockables (Classes: base / advanced / challenging;
  Starting Items, cosmetics – empty)
- Achievements – Overview (purpose, tailored system, types); Examples
  (Cartographer, Fighter, Scientist, Mystic Arts, Craftsman, Dungeon Crawler);
  Biome specific examples (Dwarven Remains, Welcome to the Jungle); Loose Ideas
- Events – seasonal generator variants and examples
